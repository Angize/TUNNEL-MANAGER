# 🌐 tnl-central

**کنترل‌پنلِ مرکزیِ مدیریتِ فلیتِ تونل‌ها**

پنلِ وبِ سبک و تک‌فایل برای ساخت و مدیریتِ تونل‌های نودبه‌نود (VXLAN / GRE / SIT) و پورت‌فوروارد،
روی ده‌ها تا صدها سرور — همه از یک داشبوردِ واحد.

## ✨ این چیه؟

`tnl-central` فقط روی **سرورِ مرکزی** اجرا می‌شود. اپراتور با یوزر/پسورد وارد می‌شود و پنل یک رجیستری از
ایجنت‌های نود (host\:port + توکن) نگه می‌دارد و از طریق HTTP به آن‌ها فرمان می‌دهد تا تونلِ نودبه‌نود بسازند،
کلِ فلیت را ببیند و وضعیت و آمارِ زندهٔ هر نود را نشان دهد.

> 🔑 نکتهٔ کلیدیِ معماری: مرکزی **فقط کنترل‌کننده است**؛ ترافیکِ تونل مستقیم بینِ دو نود جریان دارد و **هیچ‌وقت از مرکزی رد نمی‌شود**.

---

## 🚀 قابلیت‌ها

| | |
|---|---|
| 🧩 **تونلِ نودبه‌نود** | VXLAN و GRE (روی OpenvSwitch) و SIT (IPv6)، با ساختِ دو‌طرفه و rollbackِ خودکار |
| 🔀 **پورت‌فوروارد** | فورواردِ TCP/UDP روی یک نود، با چرخشِ خودکارِ چند مقصد |
| 📊 **مانیتورینگِ زنده** | CPU / RAM / دیسک، نرخ و مجموعِ ترافیک، نوارِ آپ‌تایمِ هر نود |
| ⚡ **مقیاس‌پذیر** | پایشِ فلیت در پس‌زمینه + کش؛ بازشدنِ صفحه مستقلِ از تعدادِ نودها سریع می‌ماند |
| 🔄 **بروزرسانیِ ایجنت از پنل** | سورسِ جدیدِ نود را بارگذاری و روی فلیت push کن — بدونِ SSH |
| 🩹 **خودترمیمی هنگام تغییرِ آی‌پی** | تشخیص و ترمیمِ خودکارِ تونل وقتی آی‌پیِ نود عوض می‌شود (به‌علاوهٔ check-inِ نود) |
| 🌐 **پروکسیِ کنترلی** | مسیردهیِ ترافیکِ کنترلِ هر نود از SOCKS5 / HTTP CONNECT |
| 🔐 **احراز هویت** | PBKDF2 برای پسورد، سشنِ امضاشده (HMAC)، محدودیتِ نرخِ لاگین |
| 🎨 **رابطِ کاربری** | فارسی، راست‌به‌چپ، تمِ روشن/تیره، پالتِ فرمان (Ctrl+K) |

## 🧩 معماری

```
                     ┌─────────────────────────┐
                     │        tnl-central       │  ← کنترل‌پنل (فقط فرمان می‌دهد)
                     │   پنلِ وب + رجیستریِ نودها │
                     └────────────┬────────────┘
                       فرمان over HTTP (توکن‌دار)
             ┌──────────────────┼──────────────────┐
             ▼                  ▼                  ▼
        ┌─────────┐        ┌─────────┐        ┌─────────┐
        │  نودِ A  │        │  نودِ B  │        │  نودِ C  │
        └────┬────┘        └────┬────┘        └────┬────┘
             └──────── تونلِ مستقیمِ نودبه‌نود ────────┘
                  (ترافیک هیچ‌وقت از مرکزی رد نمی‌شود)
```

ایجنتِ نود در ریپوی جداگانه است 👉 [**tnl-node**](https://github.com/Angize/TUNNEL-MANAGER-NODE)

## 📦 پیش‌نیازها

- یک سرورِ **Linux** با **systemd**
- **Python 3.7+** (فقط کتابخانهٔ استاندارد — هیچ وابستگیِ خارجی‌ای ندارد)
- دسترسیِ root (برای نصبِ سرویس)

---

## ⚙️ نصب

```bash
# ۱) فایل را روی سرورِ مرکزی بگذار
git clone https://github.com/Angize/TUNNEL-MANAGER.git
cd TUNNEL-MANAGER

# ۲) نصب: یوزر/پسورد/پورت را می‌پرسد و سرویسِ systemd را راه می‌اندازد
sudo python3 tnl-central.py --install
```

بعد از نصب، آدرسِ پنل چاپ می‌شود (پیش‌فرض پورت `8080`):

```
http://<آی‌پیِ-سرور>:8080/
```

> پسورد را بعداً می‌توانی با `sudo python3 tnl-central.py --set-pass` عوض کنی.

---

## 🖥️ استفاده

اجرای بدونِ آرگومان، منوی مدیریت را باز می‌کند:

```bash
sudo python3 tnl-central.py
```

| گزینه | کار |
|---|---|
| **Install / reinstall** | نصب یا نصبِ مجدد + راه‌اندازیِ سرویس |
| **Show URL** | نمایشِ آدرسِ پنل |
| **Restart service** | ری‌استارتِ سرویس (اعمالِ فایلِ به‌روزشده) |
| **Change port** | تغییرِ پورتِ پنل |
| **Change password** | تغییرِ یوزر/پسورد (همهٔ سشن‌های باز باطل می‌شوند) |
| **Status** | وضعیتِ سرویس، تعدادِ نودها و لینک‌ها |
| **Uninstall** | حذفِ سرویس (رجیستریِ نودها و لینک‌ها حفظ می‌شود) |

### افزودنِ نود در پنل
روی هر نود دستورِ `sudo python3 tnl-node.py --show` را بزن تا **host / port / token** را بگیری، بعد از تبِ «نودها» در پنل ثبتش کن.

## 🩹 خودترمیمی هنگام تغییرِ آی‌پیِ نود

اگر آی‌پیِ عمومیِ یک نود عوض شود، دو مکانیزمِ مکمل کار را درست می‌کنند:

- **check-in (نود → مرکزی):** نود آدرسِ مرکزی را از هدرِ درخواست‌های ورودی یاد می‌گیرد و وقتی آی‌پیش عوض شد به `/api/checkin` خبر می‌دهد؛ مرکزی `host` را فقط وقتی به‌روز می‌کند که دیگر به نود نمی‌رسد.
- **reconciler (مرکزی، دوره‌ای):** تونلی که آی‌پیِ endpointش drift کرده را می‌یابد و روی نودِ **تک‌آی‌پی** خودکار بازسازی می‌کند؛ نودِ **مولتی‌آی‌پی** فقط هشدار می‌گیرد تا اپراتور آی‌پیِ درست را از یک انتخابگرِ تگ‌دار انتخاب کند.

رفتار در **تنظیمات** قابلِ تغییر است: حالتِ `auto` (بازسازیِ خودکار) یا `alert` (فقط هشدار)، و بازه‌های بررسی.

---

## 🔐 امنیت

- روی **HTTP ساده** کار می‌کند؛ کوکیِ سشن قابلِ شنود است. **روی شبکهٔ مطمئن/VPN اجرا کن یا پشتِ TLS بگذار.**
- اگر پشتِ TLS بود، در `web.conf` مقدارِ `"tls": true` را بگذار تا کوکی فقط روی HTTPS برود.
- توکنِ نودها و پسوردِ ادمین را محرمانه نگه دار؛ پورتِ ایجنتِ نود را فقط به سرورِ مرکزی باز کن.

## 📁 مسیرِ داده‌ها

همه‌چیز زیرِ `/opt/tnl-central/` ذخیره می‌شود:

| فایل | محتوا |
|---|---|
| `web.conf` | یوزر / هشِ پسورد / سکرتِ سشن / پورت |
| `nodes.json` | رجیستریِ نودها (host\:port + توکن + پروکسی) |
| `links.json` | لینک‌های تونل |
| `traffic.json` | مجموعِ مادام‌العمرِ ترافیک (بینِ ری‌استارت‌ها می‌ماند) |
| `settings.json` | تنظیماتِ اپراتور |
| `agent.py` | سورسِ ایجنتِ نود که برای push ذخیره شده |
